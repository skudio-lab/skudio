快速使用說明

先匯入專案資料夾，再依序建立步驟、加入圖片與標註，最後儲存即可。

1. 匯入專案

選擇包含 project.json 與 images/ 的資料夾。建議使用 Chrome 或 Edge。

2. 建立與編輯步驟

按時間軸下方的＋新增卡片；可直接拖曳卡片調整順序及左、中、右位置。

3. 加入圖片與標記

點擊、拖放圖片，或將游標停在畫布後按 Ctrl + V 貼上截圖。標記可拖曳，Shift＋拖曳或滾輪可縮放。

4. 儲存專案

按儲存會更新 project.json；新圖片會自動寫入 images/。

滿版按鈕會讓卡片置中並擴展至與頂端 bar 相同的內容寬度。
